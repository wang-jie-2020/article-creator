05
概念 01

Subagent — 主编的实习生团队

"

把"查资料"派给实习生 A，"整理数据"派给实习生 B，"找案例"派给实习生 C。每个人只干一件事，干完汇报。你汇总、审核、成稿。

AI 在后台生成多个子代理，它们同时跑、互不干扰、并行加速。单个 AI 的注意力有限，Subagent 把大任务拆碎，每个小任务在干净的上下文里独立完成。

06
概念 02

Hooks — 自动驾驶的传感器

"

出门前"门一关"这个动作，自动触发"检查钥匙带没带"——不需要你每次手动提醒自己。

→发消息前 — 自动检查有没有粘贴密钥
→编辑文件后 — 自动运行代码格式化
→会话结束后 — 自动记录文件版本信息
07
概念 03

MCP — USB-C 万能转接头

"

没有 MCP 之前：让 AI 查数据库、发 Slack、看 GitHub——每一项都要写一套定制代码，像每次出国要带不同转换插头。

有了 MCP 之后：一个标准协议，所有工具即插即用。

把 AI 想象成一位盲人 CEO。他的对讲机（MCP）可以命令不同部门替他干活——"帮我查一下上个月数据"、"在 GitHub 上创建一个 issue"。

08
概念 04

Skill — 预制菜操作说明书

"

你是导演，摄像师有一份"拍摄手册"——喊一句"拍街头风格"，他就自动按手册调好参数。不需要每次从头教光圈、构图、色调。

每个 Skill 是一组"提示词 + 规则 + 参考材料"的打包。加载即用——写代码、写文章、画图表、做 PPT，任何需要反复执行且有固定方法论的任务。

09
概念 05

Claude.md — 贴在墙上的员工守则

"

你开了一家餐厅。Claude.md 不是每天给厨师的"今天做什么菜"菜单——它是贴在厨房墙上的食品安全条例和出品标准。不用每天重读，但它永远在生效。

没有 Claude.md：每次打开 AI，先花 5-10 分钟介绍自己。AI 像第一天入职的新同事。
有 Claude.md：AI 在对话开始前被"预加载"了关于你的一切。消除每一次对话的冷启动成本。
